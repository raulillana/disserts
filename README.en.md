# Disserts

*[Español](README.es.md)*

Essays on subjects I care about, written to think out loud and published so that others can discuss, cite or rebut them.

Each essay tries to do three things:

- **Make a clear argument**, even when it starts as a joke.
- **Use verifiable data**, with linked sources and, where there are charts, the data and code to reproduce them.
- **Be honest about its limits**: what the text shows, what it doesn't, and the strongest objections.

## How it is organised

- Each top-level folder is a category (for example, `IA/`, for artificial intelligence).
- Inside, each essay has one folder per language, with an **ID number** and a **codename** in that language: `IA/0-silicon-summer/` (English) and `IA/0-verano-de-silicio/` (Spanish) are the same essay, number 0.
- Each folder holds the document, named after its title, its images in `img/` and its data in `data/` (`datos/` in Spanish).

## On the writing

These essays are written with the help of AI tools (such as ChatGPT and Claude), which also help to find data, prepare the charts and translate. The author reviews the originals; translations say so when he has not yet reviewed them. The ideas, the decisions and the signature are his.

# Disertaciones

Ensayos sobre temas que me interesan, escritos para pensar en voz alta y publicados para que otros puedan discutirlos, citarlos o rebatirlos.

Cada disertación intenta cumplir tres cosas:

- **Una tesis clara**, aunque a veces empiece como un chiste.
- **Datos comprobables**, con las fuentes enlazadas y, cuando hay gráficos, los datos y el código para reproducirlos.
- **Honestidad sobre sus límites**: qué demuestra el texto, qué no, y las objeciones más fuertes.

## Cómo está organizado

- Cada carpeta de primer nivel es una categoría (por ejemplo, `IA/`).
- Dentro, cada disertación tiene su propia carpeta con un nombre en clave (por ejemplo, `IA/verano-de-silicio/`).
- En esa carpeta están el documento, que se llama como su título, sus imágenes en `img/` y sus datos en `datos/`.

## Sobre la escritura

Estas disertaciones se escriben con ayuda de herramientas de IA (como ChatGPT y Claude), que también ayudan a buscar datos y preparar los gráficos. Todo lo revisa el autor, y las ideas, las decisiones y la firma son suyas.
